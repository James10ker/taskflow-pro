# Attribution

The frontend in this repository is based on [Siggmond/taskflow-pro](https://github.com/Siggmond/taskflow-pro), originally authored by Ahmad (`AhmadsaaD111`) and distributed under the MIT License.

The upstream project is a Vue 3 + TypeScript frontend whose REST API, authentication, authorization, and persistence are demonstrated through an in-browser mock adapter and `localStorage`.

This derivative project keeps the upstream license and attribution. It adds a real Spring Boot backend, relational database design, server-side authentication/authorization, deployment infrastructure, and—only in later planned phases—AI capabilities. The original frontend is not claimed as original work of this derivative project.
